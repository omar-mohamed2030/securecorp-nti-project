01 / Overview

Every layer of a real enterprise network, in one lab build.

SecureCorp is a fictional company used as the basis for this project: a headquarters site with redundant core infrastructure, two branch offices connected over WAN, and a full set of internal services. The build covers routing, switching, security, wireless, voice, and address translation as a single cohesive design rather than isolated exercises.

02 / Requirements

All ten project requirements, implemented and tested.

Routed network
Every VLAN routed at redundant core SVIs; branches use router-on-a-stick.
Routing — Static + OSPF
Multi-area OSPF backbone, static default routes redistributed to every site.
Security
Port security, SSH + local AAA, extended ACL isolating the guest network.
VLAN segmentation
HR, Finance, IT, Servers, Voice, Wi-Fi Staff, Wi-Fi Guest, Management.
Core services
DHCP, DNS, HTTP, FTP, and email — centralized and relayed to every VLAN.
EtherChannel
LACP-bundled links between core switches for throughput and redundancy.
FHRP — HSRP
Active/standby gateway redundancy split across both core switches.
WLAN
Separate staff and guest SSIDs, each mapped to its own VLAN and policy.
NAT
PAT for general internet access, static forwarding for public-facing servers.
IP telephony
Cisco CME voice gateway; phones registered at HQ and both branch sites.
